Exercício 02 — Fundamentos de Programação

Este diretório contém a implementação do exercício 2 da disciplina de Fundamentos de Programação, desenvolvido em Java.

📂 Arquivos

Alunos.java — Classe que representa um aluno, com seus atributos, notas, frequência e métodos para calcular o grau G1 e verificar a aprovação.

Aplicacao.java — Classe principal responsável pela interação com o usuário, leitura das notas e frequência e apresentação dos resultados.

🛠️ Conceitos utilizados

Programação Orientada a Objetos (POO)

Classes, objetos e atributos privados

Encapsulamento

Construtores e métodos de instância

Métodos getters e setters

Estruturas condicionais

Entrada de dados com Scanner

▶️ Como executar

Execute a classe Aplicacao em um ambiente Java compatível, como o VS Code com suporte a Java.

Desenvolvido como parte das atividades acadêmicas da graduação em Engenharia de Software.
