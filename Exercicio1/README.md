💳 Sistema de Conta Bancária

Projeto desenvolvido em Java para praticar conceitos de Programação Orientada a Objetos (POO).

⚙️ Funcionalidades

Criação de conta bancária com titular, identificador e saldo inicial.

Depósito e saque com validação de valores.

Consulta dos dados da conta e do saldo disponível.

Encapsulamento de atributos.

🛠️ Tecnologias

Java

Programação Orientada a Objetos (POO)

🎯 Objetivo

Aplicar conceitos fundamentais de Java por meio da implementação de operações básicas de uma conta bancária.
